03Process

How I work

A clear, phased method so every delivery makes sense for the business and works well from day one.

  1. 01

    Understand the business

    I gather requirements with each area, analyze processes and identify what creates value.

  2. 02

    Design the solution

    I define the scope, architecture, data model and a phased plan with deliverables.

  3. 03

    Build in phases

    I build each module with incremental deliveries and integrate it into the system.

  4. 04

    Validate quality

    I review, test and debug every delivery, using Git and GitHub for traceability.
